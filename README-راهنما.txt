راهنمای نسخه تکمیل‌شده سامانه مدیریت استراحت طلاین

محتویات بسته:
- index.html: فایل اصلی سامانه
- firestore.rules: قوانین امنیتی Firestore

امکانات حفظ‌شده و تکمیل‌شده:
- ورود و ایجاد حساب کارشناس با Firebase Authentication
- پنل کارشناس و مدیر
- شروع و پایان استراحت فوری و مشاهده سوابق
- فهرست کاربران و تغییر نقش مدیر از Firebase Console
- گزارش ترددها و نمایش کارشناسان آنلاین/آفلاین/در حال استراحت
- رزرو استراحت در تاریخ و ساعت آینده توسط کارشناس، با مدت ۱ تا ۶۰ دقیقه
- مشاهده رزروهای همه کارشناسان در پنل مدیر
- شروع رزرو در زمان مقرر یا پس از آن، و لغو رزرو آینده توسط خود کارشناس
- آنلاین ماندن در زمان بی‌فعالیتی موس/صفحه تا وقتی نشست سایت و اتصال شبکه برقرار باشد

نصب:
۱) index.html و firestore.rules را در مخزن GitHub Pages جایگزین کنید.
۲) در Firebase Console > Firestore Database > Rules، محتوای firestore.rules را جایگزین و Publish کنید.
۳) در Firebase Authentication > Settings > Authorized domains، دامنه mmousavilegal-eng.github.io باید ثبت شده باشد.
۴) در Authentication > Sign-in method، روش Email/Password فعال باشد.
۵) نقش مدیر باید در سند users با شناسه UID حساب مدیر، برابر admin باشد. حساب‌های جدید به‌صورت پیش‌فرض employee ساخته می‌شوند.

ساختار داده:
- users/{uid}: پروفایل و نقش
- presence/{uid}: آخرین وضعیت حضور
- breakSessions/{id}: نشست‌های استراحت انجام‌شده
- breakReservations/{id}: رزروهای آینده و وضعیت آن‌ها

نکات:
- برنامه به Firebase پروژه taline-support متصل است.
- اسناد users برای همه کاربران واردشده قابل خواندن‌اند تا فهرست همکاران نمایش داده شود؛ اطلاعات حساس در این اسناد ذخیره نکنید.
- تغییر نقش فقط از Firebase Console انجام می‌شود.
- وضعیت آنلاین با heartbeat هر ۶۰ ثانیه و اعتبار ۱۵۰ ثانیه‌ای محاسبه می‌شود. در صورت بسته‌شدن مرورگر یا قطع اینترنت، پس از مهلت مذکور وضعیت آفلاین خواهد شد.
- خطای auth/network-request-failed خطای ارتباط Firebase Authentication است و معمولاً از قوانین Firestore نیست. اینترنت، VPN/Proxy، افزونه‌های مسدودکننده، تنظیمات شبکه و دسترسی دامنه‌های Firebase را بررسی کنید. رمز عبور را برای هیچ‌کس ارسال نکنید.
- نشان لوگو از دارایی برند TALINE در Brandfetch برای دامنه tlyn.ir دریافت شده است. صفحه Brandfetch وضعیت برند را Unclaimed نشان می‌دهد؛ برای تأیید قطعی فایل رسمی باید واحد برند طلاین آن را تأیید کند.

پیش از استفاده سازمانی، با دو حساب آزمایشی ورود، رزرو، لغو، شروع و پایان استراحت را آزمایش کنید. این نسخه از نظر کد و قوانین بررسی ایستا شده و به Firebase واقعی شما دسترسی آزمایشی ندارد.
